# Fuente de las fotografías

Dataset: Intel Image Classification.
Publicación de Kaggle: Puneet Bansal, `puneet6060/intel-image-classification`, versión 2.
https://www.kaggle.com/datasets/puneet6060/intel-image-classification

La ficha atribuye el origen a un desafío de clasificación de Intel en Analytics Vidhya:
https://datahack.analyticsvidhya.com/

La API de Kaggle muestra la declaración de derechos "Data files © Original Authors". No se presenta esta colección como CC0 ni se atribuye una licencia abierta diferente. Se conserva la atribución a sus autores originales.

El notebook incluye el código de descarga de la versión utilizada. Los archivos completos no se incluyeron en el paquete. Se eliminaron copias exactas y grupos de etiquetas contradictorias antes de muestrear las imágenes. El redimensionamiento a 128 × 128 se realiza en memoria; no modifica los archivos originales.

Las seis fotografías de `ejemplos/` con nombre de clase son copias de imágenes de prueba usadas para demostrar la aplicación. `sin_etiqueta.jpg` procede de la carpeta original de predicción y no tiene etiqueta real disponible. Se comprobó que su hash no apareciera en las imágenes etiquetadas. No es una evaluación externa etiquetada.

Las figuras de muestras y demostración, también incrustadas en el notebook, muestran selecciones de estas fotografías con títulos y cambios de tamaño. Se utilizan como ilustración del análisis académico. Los derechos de las fotografías siguen correspondiendo a sus autores originales.

Los archivos de auditoría y particiones documentan las rutas y hashes de las fotografías etiquetadas utilizadas.
